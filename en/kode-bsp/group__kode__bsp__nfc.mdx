)

Single-shot detect-and-select of a Mifare Classic 1K card. 

**Parameters**: 

  * **out** Card descriptor (UID, ATQA, SAK). 


**Return**: ESP_OK on detect+select, ESP_ERR_TIMEOUT if no card present, ESP_ERR_NOT_SUPPORTED if the card is not Mifare Classic 1K. 

### function kode_nfc_mifare_auth_start

```
static inline esp_err_t kode_nfc_mifare_auth_start(
    uint8_t block,
    uint8_t key_type,
    uint8_t nonce_out[4]
)
```

Mifare Classic AUTH step 1 — request a nonce from the card. 

**Parameters**: 

  * **block** Target block number (0..63). 
  * **key_type** 0 = Key A (0x60), 1 = Key B (0x61). 
  * **nonce_out** 4-byte nonce returned by the card. 


Must be called immediately after [kode_nfc_read_uid()](/en/kode-bsp/group__kode__bsp__nfc#function-kode-nfc-read-uid) while the card is still in ACTIVE state.


### function kode_nfc_mifare_auth

```
static inline esp_err_t kode_nfc_mifare_auth(
    uint8_t block,
    uint8_t key_type,
    const uint8_t key[6],
    const uint8_t uid[4]
)
```

Full Mifare Classic Crypto1 authentication for a given block. 

**Parameters**: 

  * **block** Target block number. 
  * **key_type** 0 = Key A, 1 = Key B. 
  * **key** 6-byte sector key. 
  * **uid** 4-byte UID returned by [kode_nfc_read_uid()](/en/kode-bsp/group__kode__bsp__nfc#function-kode-nfc-read-uid). 


Must be called after [kode_nfc_read_uid()](/en/kode-bsp/group__kode__bsp__nfc#function-kode-nfc-read-uid). On success the Crypto1 stream cipher is set up and subsequent read/write operations on this block are accepted.
